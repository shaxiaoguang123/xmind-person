# Product Specification

## Core Workflow

Markdown documents are transformed into semantic sections and visual graphs.

## Requirement IDs

- MD-001 Markdown AST parsing
- GRAPH-001 independent graph model
- LAYOUT-001 deterministic multi-pass layout
- UI-001 professional canvas editor
- UX-001 keyboard-first interaction
- API-001 document persistence
- TEST-001 layered testing strategy

## Non Goals for MVP

No collaboration, plugin marketplace, AI agents, or mobile full editor.
